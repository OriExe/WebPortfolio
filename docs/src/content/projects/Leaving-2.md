# Leaving 2...
Leaving 2 is the enhanced version of Leaving I've made previously for my coursework and improved upon it as part of a work based learning event at my university. I worked with a team to help improve the game and our goal was to develop a customer base for this game. Using the feedback from our survey and the itch io comments we set out to improve the game with the changes that our future customers wanted to see. We added gameplay elements that enhanced the progression system and made the game more replayable and improved the accessibility so that new players can understand the game more easilly.
