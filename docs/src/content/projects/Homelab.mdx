# Self hosted Server
As my photo gallery was filling up and I needed more storage space to save my past photos while also allowing them to be easilly accessible I repurposed an old laptop and used it's  external hard drive to run an  Immich container with Docker, a self hosted photo gallery tool. I installed Ubuntu 24.04 LTS on my laptop, modified my fstab file to mount my external hard drive and it worked flawlessly.
