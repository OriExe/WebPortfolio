# Tim the Robot
This is my submission for one of my course-related modules at university. I made a flying robot that takes advantage of the geometry nodes feature in Blender and replaces each vertex with an ico sphere to create the holographic effect when enabled.In addition to making the 3D model, I was also tasked with creating an AR app that features this model. 
I used a software called Vuforia, which allowed me to display the model over a 2D image in the real world that I scanned into the Vuforia database. 
Got a first class grade with feedback from my module leader
